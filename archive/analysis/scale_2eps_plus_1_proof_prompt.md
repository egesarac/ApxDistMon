### Separate the two claims

Give independent verdicts for these propositions. A proof of the second does
not prove the first.

1. **Literal-patch proposition.** Keeping every other predicate in the current
   `random.py` implementation unchanged, does replacing only the scale with
   `K = 2*eps + 1` make both timed monitor entry points semantically exact?
   Account for the current cell-valued clocks, inverse-domain disjunctions,
   pointwise cell skew, happened-before constraints, monotonicity constraints,
   quantified tick query, endpoints, and finite-tail handling.

2. **Ideal integer-knot proposition.** Define the following model, distinct
   from the literal encoding. For every agent `i in {0,1}` and every integer
   local boundary `j in {0,...,d}`, introduce an integer inverse-clock tick
   `z[i,j]`. Introduce the fixed reference ticks `z[ref,j] = K*j`. Require
   `z[i,0] = 0`, `z[i,d] = K*d`, and
   `z[i,j] < z[i,j+1]` for every `j < d`. For every ordered pair of distinct
   clocks `alpha,beta in {ref,0,1}` and every integer
   `j in {0,...,d-eps}`, require the strict shifted inequality
   `z[alpha,j] < z[beta,j+eps]` (with no such inequalities when `eps > d`).
   Let `g_i` be the unique piecewise-linear interpolation through
   `(j,z[i,j]/K)` on `[0,d]`, let `c_i = g_i^{-1}`, restrict the clocks and
   reconstructed retiming to `[0,d)`, and evaluate `phi` with the dense-time
   paper semantics on that retiming. The finite true-run coverage condition is
   a proposed decision reduction, not the definition of satisfaction: prove
   its exact equivalence to this dense predicate, including every endpoint and
   finite-tail case. Is `K = 2*eps + 1` sufficient for verdict equivalence for
   all supported inputs?

If the literal implementation is not equivalent to the ideal knot model for
arbitrary `K`, identify the exact additional discrepancy before analyzing the
scale bound.

### Exact theorem to decide

Define `T_cont` as the paper-semantic admissible retimings consistent with the
fixed least happened-before relation above. Keep the two grid objects separate:

- `M_K_lit` is the set of complete assignments satisfying the unchanged base
  predicates of the literal `random.py` encoding when only `scale`/`pad` is
  set to `K`. Let `Q_K_lit_pos` be the exact predicate added by the current
  `query == "not_response"` branch (a tick-level satisfying response flow),
  and let `Q_K_lit_neg` be the exact predicate added by the current
  `query == "response"` branch (a tick-level violating response flow). These
  names describe formula polarity, not the monitor entry-point return value.
  Do not write `w |= phi` for a literal assignment unless a dense retiming and
  preservation theorem have first been defined and proved.
- `T_K_knot` is the set of dense retimings reconstructed from the ideal integer
  knot assignments defined in proposition 2. Membership uses the stated knot
  constraints and piecewise-linear reconstruction; formula satisfaction is
  the dense-time paper predicate, not tick sampling or true-run coverage by
  definition.

For the literal-patch proposition, decide both equivalences:

1. `exists w in T_cont: w |= phi` if and only if
   `exists m in M_K_lit: Q_K_lit_pos(m)`;
2. `exists w in T_cont: w |= not phi` if and only if
   `exists m in M_K_lit: Q_K_lit_neg(m)`.

For the ideal integer-knot proposition, independently decide:

1. `exists w in T_cont: w |= phi` if and only if
   `exists w in T_K_knot: w |= phi`;
2. `exists w in T_cont: w |= not phi` if and only if
   `exists w in T_K_knot: w |= not phi`.

For either grid object, three-valued verdict correctness follows only when both
polarity equivalences for that object hold. Do not disprove a stronger but
irrelevant claim merely by observing that a particular irrational clock is not
itself a grid clock: the question is whether the grid preserves the existence
of each formula polarity.

### Required proof obligations

A proof must establish, rather than assume, all of the following:

1. A finite characterization of the relevant paper-semantic retimings using
   signal edges or inverse-clock knots, including endpoints and consistency.
2. Exact reduction of dense-time response truth to finite constraints,
   respecting right continuity, open/closed endpoints, connected chains of
   response windows, and the finite horizon.
3. **Literal-grid soundness:** every `M_K_lit` assignment satisfying
   `Q_K_lit_pos` or `Q_K_lit_neg` reconstructs an admissible, consistent
   clock family with the corresponding dense-time formula polarity.
4. **Literal-grid completeness for each polarity:** every satisfiable
   continuous branch has some `M_K_lit` assignment satisfying the
   corresponding literal query.
5. **Ideal-knot soundness:** the shifted inequalities under the stated
   piecewise-linear reconstruction imply strict all-time skew, consistency,
   and the same dense formula polarity. This includes proving the finite
   true-run coverage reduction rather than taking it as the semantics.
6. **Ideal-knot completeness for each polarity:** every satisfiable continuous
   branch has some `T_K_knot` representative preserving that polarity.
7. Both polarity-existence equivalences for each grid object and therefore its
   three-valued verdict.

If using a difference-constraints or cycle argument, derive the actual
constraint graph generated by this clock model and response syntax. Prove the
required bound on strict edges versus integral slack. A generic denominator
bound depending on the number of variables does not prove the
duration-independent bound `2*eps + 1`. Explicitly determine whether strict
chains whose required denominator grows with `d` are realizable by actual
signals and response branches.

### Requirements for a disproof

A disproof must provide a realizable semantic instance, not merely an arbitrary
strict-DBM counterexample. Give:

- explicit integer `d`, `eps`, `a`, and `b`;
- explicit `p` and `q` bitstrings, including their terminal-marker values in
  the repository format;
- the exact direction that fails: soundness or completeness, and satisfying or
  violating polarity;
- exact rational inverse-clock knots or an equivalent exact description of the
  continuous witness; decimals alone are insufficient;
- verification of strict skew for all physical times, endpoint behavior,
  happened-before consistency, and the dense-time formula polarity;
- a hand-checkable proof that no corresponding `K = 2*eps + 1` grid model of
  that polarity exists, or an explicit grid model showing unsoundness;
- a deterministic standalone reproducer, preferably under `/tmp`, with the
  exact command, Z3 version, and raw result.

Search for a small counterexample in a stated lexicographic order before
claiming the proposition. Computation may support the mathematical argument,
but finite testing over bounded ranges is not a proof of a universal claim.
